# Contributing

Suggestions are welcome. This list stays useful by staying strict: only well-known, public tools with a real project page.

## How to suggest a tool

Open an issue or a pull request with:

1. **Tool name** and the category it belongs in.
2. **Official link** — the project's GitHub repo or official site. No affiliate links, no tracking parameters, no link shorteners.
3. **One-line description** — what the tool does, in plain words.
4. **Why it belongs** — a sentence on what makes it well-known or widely used (e.g. standard in write-ups, maintained, large community).

## Rules for additions

- The tool must be **public** and **maintained or well-known**. Abandoned one-off scripts do not belong here.
- Commercial tools are fine only if they have a real free tier (e.g. Burp Suite Community). Paid-only tools do not belong here.
- No fake, renamed, or typo-squatted projects. If a link 404s or redirects somewhere unexpected, it will be removed.
- No exploitation guidance, payloads, or target-specific instructions — this repo lists tools, it does not teach attacks. Everything here is for authorized testing only.
- Keep descriptions to one honest line. No hype ("best", "ultimate", "undetectable").

## Fixing a dead link

If a link is dead or a project moved, open a pull request with the corrected official link — or an issue if you are not sure where it moved. A tool whose project is gone gets removed from the list.
